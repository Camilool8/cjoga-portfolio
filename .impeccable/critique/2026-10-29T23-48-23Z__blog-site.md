## Owner clarification (2026-10-29)

The learner red flag "runbooks promised but no command blocks" is withdrawn. The guides are deliberately meta-guides: they summarise and interpret runbooks that live elsewhere (e.g. the RHCSA guide states it is "not a re-statement of the lab's README — that lives on GitHub and stays the source of truth"). The handbook mixes these guides with personal sections: opinions, Now, Who I am, work engagements, credentials, reading and tools. Design consequence: the external lab or runbook each guide interprets should be an explicit, findable link near the top of the guide, not only an inline link in the first paragraph; reading-time cues help across the 700–1,700-word guides and essays. Owner scope: all 5 priority issues, phone + fold first.
