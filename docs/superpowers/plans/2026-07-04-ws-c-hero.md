# WS-C — Hero remediation (2026-07-04)

Workstream C of the audit-remediation wave. Scope: `src/components/Hero.jsx` only.
Source findings: `AUDIT-2026-07-04.md` §1 (typewriter, fake status dot, scroll cue),
§2 (hero-level terminal hint), §4 (`aria-live` typewriter High, 4.1.3),
§1 Low (`min-h-screen` iOS jump).

## Changes

### 1. Typewriter → crossfade (audit §1 Med, §4 High)
- Delete the per-keystroke `setInterval` state machine (`text`/`isDeleting`/`delta`)
  and the blinking `border-right` caret span with `aria-live="polite"`.
- Keep a single `roleIndex` state. A self-rescheduling `setTimeout` (4s) advances
  `roleIndex` through the existing `hero.roles` translation array — one re-render
  per 4s instead of per keystroke, and no `setInterval` anywhere in the file.
- Render via `AnimatePresence mode="wait"` + `m.span` keyed by `roleIndex`,
  opacity-only crossfade. No `aria-live`.
- Under `useReducedMotion()`: render `roles[0]` statically; the timeout effect
  bails out entirely (no cycling).

### 2. Real health status (audit §1 Med — "the one on-brand fix")
- `health` state: `"checking" → "operational" | "unavailable"`.
- On mount, one plain `fetch("/api/health", { signal: AbortSignal.timeout(5000) })`;
  `res.ok` → operational, anything else (incl. timeout/network error) → unavailable.
  Cancelled-flag guard against setting state after unmount.
- Label: static map `{ checking, operational, unavailable } → t("hero.status.<state>", defaultValue)`
  with fallbacks "checking systems…" / "systems operational" / "systems unreachable" —
  keys land at the wave gate (workstream owning locales), defaultValues cover the gap.
- Dot color (no hardcoded `#22c55e`):
  - checking → `var(--text-tertiary)` (no glow)
  - operational → `var(--accent)` (glow)
  - unavailable → `var(--accent-warm)` (glow)

### 3. Status strip slimmed to three chips
- Health chip: the only chip with a state dot (it's the only one with real state —
  directly answers the audit's "three glowing dots incl. a fake" finding).
- Certs chip: plain mono text, `t("hero.status.certs", { count: CERT_COUNT })`;
  `CERT_COUNT` imported from `./certifications/certData` (created this wave by the
  Certifications workstream; no import-resolution ESLint plugin so lints clean).
- Opportunities chip: plain mono text, kept.

### 4. Scroll cue deleted (audit §1 Med — "genre tell")
Whole `<a href="#about">` block with the traveling-line animation removed.

### 5. `min-h-screen` → `min-h-[100dvh]` (audit §1 Low)

### 6. Terminal hint near CTAs (audit §2 value-add verdict)

- App root gains `<LazyMotion strict>` in another workstream — every `motion.x`

  (Hero.jsx:13–28) stay byte-for-byte in behavior.
