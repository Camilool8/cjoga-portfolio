# Now

This is a [/now page](https://nownownow.com/about) — a snapshot of where my hours are actually going this month. It's deliberately narrow and short-lived. If you're reading this in a future quarter, it's already wrong.

## Right now

Between [Globant](/engineering/work/globant) and [Arctiq](/engineering/work/arctiq), a few threads carry most of the week:

- **Databricks as code.** Multiple workspaces deployed through Bicep, a Unity Catalog metastore per region with its permissions and compute settings, and dedicated general-purpose clusters per environment in each workspace. Azure DevOps pipelines deploy the jobs and install their dependencies, with notebooks pulled from Git. The PoC in flight moves job parameters into [Declarative Automation Bundles](https://docs.databricks.com/aws/en/dev-tools/bundles/) (formerly Databricks Asset Bundles), so the latest configuration deploys with the job.
- **Two PoCs lined up behind it.** Re-architecting the Bicep deployments around environments instead of resource types, so a greenfield environment is one deployment; and an SRE agent plugin built on Anthropic's open standards, [Agent Skills](https://agentskills.io/) and [MCP](https://modelcontextprotocol.io/), to ship to other teams across the organization.
- **SOC 2 and multi-region EKS.** The Arctiq client is expanding into new regions, so the platform is going from a single AWS region to multi-region EKS while SOC 2 readiness lands with it. Readiness is tracked in [Secureframe](https://secureframe.com/), which turns the audit into goals with owners and dates.
- **Just wrapped.** A Nutanix Kubernetes Platform (NKP) Ultimate deployment for a customer moving off OpenShift: architecture, deployment, and the documentation their team needed to own it.
- **Mentoring.** Keeping an eye on the health of my peers' projects at Arctiq, and pointing them the right way when they hit cloud, Kubernetes or security questions.

Outside the day job, [KodePull](/engineering/work/kodepull) recently delivered mobile app work and a run of web design and deployment projects, on top of the steady base of maintenance, domain renewals and hosting. The cluster this site runs on is now KodePull's [on-prem cluster](/engineering/lab/overview): the home for clients who keep their data on local hardware, and the relay and backup site for the production clusters in the cloud and in datacenters.

## Building

It was my final gate before CKAD, and I'm upgrading its CKA bank now as my own prep. No write-up on it until I've passed CKA. The [project page](/learn/kubestronaut-sim) has the story so far.
